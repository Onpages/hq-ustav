ПАМЯТКА «КАК ЗАПУСТИТЬ» (modeli):
СКРИПТ (PowerShell):
  1. Ctrl+Ё в VS Code
  2. .\имя-скрипта.ps1 → Enter
ЗАДАЧА АГЕНТУ (MD-N через 1.txt):
  1. Ctrl+Ё в VS Code
  2. Приглашение: C:\Users\HUAWEI\Downloads\modeli>
     (иначе: cd C:\Users\HUAWEI\Downloads\modeli)
  3. qwen → Enter (агент читает QWEN.md из корня)
  4. Внутри агента: @1.txt выполни → Enter
  5. Отчёт: otchet.txt в дереве слева
  6. Выход из агента: /exit или Ctrl+C
ПРАВИЛА:
  - Одна сессия агента на папку одновременно
  - Команду @ набираю руками, вставка не нужна
  - Жёлтое в Problems = можно, красное = стоп и в генштаб

   qwen (после починки PATH) или временную добавку $env:Path += ... + qwen (если решишь жить без правки PATH).
